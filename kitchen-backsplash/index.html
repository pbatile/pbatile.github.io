Kitchen Backsplash Installation in West Palm Beach

PBA Tile & Marble installs custom kitchen backsplashes for homes across Palm Beach County.

We install backsplashes for homeowners, general contractors, and builders. The same crew handles bathroom tile, shower tile, and floor tile when the project calls for it.
